# Kinetic Dashboard

This project is a UX improvement over an existing dashboard. It addresses the "Wall of UI" effect, improving scannability, visual hierarchy, and progressive disclosure for tracking leads.

## Features

- **Data Table Layout:** Fresh leads are displayed in a clean, scannable table instead of a grid of identical cards.
- **Progressive Disclosure:** Initially shows only the top 5 leads with a "View All" expand button.
- **Semantic Labels:** Label pills use clear text, semantic colors, and icons for quick identification.
- **Quick-Filter Summary:** Instantly filter leads by label type using the summary bar.
- **AI Alerts Tabular View:** AI insights are presented in an actionable list with prominent action buttons.

## Local Setup

1. **Install Dependencies**
   ```bash
   npm install
   ```

2. **Run Development Server**
   ```bash
   npm run dev
   ```

3. **Build for Production**
   ```bash
   npm run build
   ```
